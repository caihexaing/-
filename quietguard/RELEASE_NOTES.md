# 净屏 v0.4.4 · 启动兼容与扫描优化（构建10）

- 修正窗口事件会触发过密整树扫描的问题：识别移至工作线程，优先按文字查找，两次扫描完成之间至少500ms，必要时全树读取也有冷却和节点间时间预算。
- 两次点击尝试并观察后停止扫描，同一包的事件不再持续唤醒过期扫描；诊断增加最高单次读取耗时。
- 长按已开启的应用 → 防护方式，新增“仅开屏跳过（启动兼容）”。适用于拦截网络后启动慢或开屏短暂黑屏的应用：保留其正常网络，依靠跳过按钮关闭开屏广告。广告可能短暂出现，页面内其他广告不再使用域名过滤。
- 默认保留现有网络过滤+开屏跳过。仅跳过应用从VPN处理列表排除；全部应用只跳过时无需启动VPN，更新后也不会为它们重开VPN。
- 原有纯跳过兼容独立保留；开启也可能跳过该应用的教程或登录引导。保留应用内更新进度、净屏VPN自动暂停/恢复和安装校验。

建议住理生活用户更新后长按它，改为“仅开屏跳过（启动兼容）”再对比启动。已通过编译、Android Lint和277项逻辑检查及20,000组随机报文；尚无连接真机，未确认用户黑屏的具体原因，也未确认本版能消除该等待。纯图片或未开放控件仍可能无法识别，无法保证消除所有广告。

# 净屏 v0.4.7 · 按应用文字定位点击兼容（构建13）

- 用户的住理生活0.4.6诊断明确显示“跳过文字外层过大或越界”，本次没有发送点击。本版保留大容器拒绝规则，新增“文字定位点击（兼容，可能误触）”，默认关闭，需为住理生活单独开启。
- 长按住理生活 → 防护方式 → 勾选“文字定位点击（兼容，可能误触）” → 保存。若诊断提示系统未授予定位触摸能力，请到系统无障碍关闭后重新开启净屏，再返回确认已就绪。
- 仅在普通语义按钮解析因外层过大或缺少动作而失败时，识别唯一、明确的小尺寸跳过文字叶子。连续两次扫描必须确认同一节点、包、窗口和位置稳定；点击前再次刷新和核对，然后只触摸文字中心一次。不固定右上角、不点击大广告容器。
- 普通控件点击与文字定位触摸共用每次进入的一次操作额度，禁止点击后再补手势。被系统取消、拒绝或中断均不重试。定位模式关闭、锁屏、窗口变化或系统放大开启时放弃。
- 诊断显示定位兼容开关、操作类型、点击目标与系统触摸回调；回调完成和计数增长不表示广告清除。保留更新VPN自动暂停/恢复和应用内下载进度。

定位触摸仍有误触风险：界面变化、遮挡和错误控件信息可能使它命中广告；发生误跳请关闭该应用的定位兼容。已经通过451项逻辑断言、13项源码守卫、20,000组随机报文、编译和Android Lint，尚无连接真机，不能保证住理生活已能跳过或不再跳转。

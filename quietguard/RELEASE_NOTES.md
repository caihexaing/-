# 净屏 v0.4.9 · 一次授权后快捷开启（构建15）

- 增加可选的电脑一次授权：授予 WRITE_SECURE_SETTINGS 后，在净屏内点击“开启开屏广告跳过”即可设置自身无障碍开关，无需每次进入系统设置，也无需持续连接 USB。不需要 Root。
- 首次仍需同意界面读取和点击用途说明。只在用户点击时设置，不在后台强行恢复用户关闭的服务；保留其他无障碍服务。
- 设置页显示快捷开启授权状态。未授权或系统拒绝时，保留系统设置入口。卸载、撤销权限或系统策略变化后可能需要再次授权；普通安装不会自动获得此权限。
- 保留0.4.8一键开启普通应用、每个应用兼容设置、应用内更新进度及更新期间净屏 VPN 暂停/恢复行为。

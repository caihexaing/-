# 净屏 v0.4.11 · 规则更新基础模块（构建17）

- 新增独立规则包验签模块，检查签名、版本下限、应用兼容性、文件哈希与域名格式。
- 源码新增离线规则转换工具，支持 hosts、纯域名及受支持的 Adblock 域名规则，保留例外；不支持的例外会使整个来源被拒绝。
- 新增规则更新协议及回归检查，为后续接入下载、存储与运行时加载提供基础。
- 保留 0.4.10 的开屏跳过、应用选择、兼容设置和应用内 APK 更新。

本版是基础模块发布：规则下载、生产规则签名和运行时加载尚未接入，没有新增规则更新按钮，候选规则未启用。手机上的广告拦截与跳过行为与 0.4.10 相同，不代表广告清除率或跳过速度提升。没有连接手机进行广告效果实测。

# 净屏 v0.4.0

- 更新改为净屏内下载，不再打开浏览器。
- 显示真实下载进度条、百分比、文件大小和速度，支持取消、收起与失败后重试。
- 系统管理后台下载；回到净屏恢复进度，等待网络时显示真实状态。
- 下载完成校验 SHA-256、包名、版本和签名，通过后可直接打开系统安装确认界面。
- 首次安装更新引导授予“允许净屏安装应用”，返回后继续安装；不需要存储权限。
- 保留应用开关、DNS 过滤、开屏跳过及域名例外。

0.3.0 及更旧版本需要先手动安装本版一次，之后的新版本即可在净屏内下载并显示进度。最终安装仍需系统确认。

通过编译、Android Lint、177 项逻辑检查及 20,000 组报文测试；当前无连接真机，下载/系统安装交互与开屏广告跳过效果仍待设备验证。无法保证清除全部广告。

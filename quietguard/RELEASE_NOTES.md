# 净屏 v0.3.0

- 新增开屏广告自动跳过，识别类似截图右上角“4s｜跳过”的控件。
- 原应用开关同时控制 DNS 网络过滤和自动跳过，首页及通知的暂停可停止两种处理。
- 自动跳过需要手动开启“净屏 · 开屏广告跳过”无障碍服务，首页显示真实授权/连接状态。
- 仅处理选中应用进入前台后 15 秒内的明确跳过控件，限制位置、尝试次数和点击范围，不盲点广告页面。
- 将“拦截/失败”改为“规则命中/转发失败”，另列跳过点击操作次数，不再暗示广告已被全部清除。
- 保留 GitHub 更新检查、独立应用选择、搜索和域名例外。

升级后请点击首页“开启开屏广告跳过”，阅读用途并前往系统设置授权；返回确认“已就绪”，再重新打开住理生活测试。广告可能短暂出现。

已通过编译、Android Lint 和 147 项逻辑检查及 20,000 组报文测试；未连接真机，尚未验证住理生活的实际控件树与广告跳过效果。不能保证清除所有应用的全部广告。

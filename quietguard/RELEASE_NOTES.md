# 净屏 v0.4.5 · 减少开屏跳过误触（构建11）

- 针对住理生活开屏广告闪现后跳转推广页的反馈，移除可能误触的父容器点击、坐标手势和点击后的补点；无障碍配置同时关闭手势能力。尚无真机日志，不能认定是哪条路径造成这次跳转。
- 每次应用进入前台的识别窗口内，最多向跳过控件自身发送一次 ACTION_CLICK 请求。控件必须自身可点击，属于当前应用和窗口，并通过刷新、可见性、启用状态、大小和文字核对；请求被拒绝或中断也不补点。
- 如果控件文字和描述不一致，例如文字为“跳过”、描述为“下载”或“立即进入”，放弃点击。不支持直接点击的文字也放弃，部分应用可能因此无法自动跳过。
- 最近跳过诊断新增“本次点击”，记录是否发送过控件点击请求，方便区分净屏操作与应用自行跳转。系统接受请求不等同于广告已清除，也不能证明跳转一定由净屏引起。
- 保留0.4.4的工作线程扫描、限频、按应用“仅开屏跳过（启动兼容）”，以及应用内更新进度、更新期间净屏VPN自动暂停/恢复和安装校验。

更新后退出并重新打开住理生活。如仍发生跳转，请在净屏设置查看最近跳过诊断，记录“本次点击”和原因。已通过编译、Android Lint、298项逻辑断言、7项源码守卫及20,000组随机报文；尚无连接真机，不能确认本版已解决该手机上的跳转，也无法保证跳过所有广告或阻止应用自行跳转。

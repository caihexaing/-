# 净屏 v0.4.6 · 跳过按钮兼容与诊断修正（构建12）

- 用户截图确认住理生活曾读到“跳过”和广告标识，但未发送点击请求；0.4.5只允许文字节点自身点击，存在对小型外层按钮不兼容的情况。截图本身不能确认实际拒绝条件。
- 新增受限语义按钮核对：文字节点不提供动作时，最多检查两层外层，只有紧贴跳过文字、完整内容仅含跳过/倒计时/短广告标识且公开点击动作的小按钮才允许点击。拒绝过大容器、推广文字、未知图标、多入口、跨应用/窗口、失效和读取不完整的结构。
- 保持每次进入最多一次控件点击，不使用坐标手势、不补点、不执行全局返回。点击前再次核对按钮。支持只公开点击动作但没有同步clickable标志的节点；请求是否有效仍由应用和系统决定。
- 修复诊断被覆盖：关键按钮拒绝或点击结果单独保留，后续“暂时无法读取窗口”仅更新最近状态。增加点击目标类型，新会话清理旧目标记录。
- 保留应用内更新进度、净屏VPN更新期间自动暂停与恢复、按应用仅开屏跳过及扫描限频。

已通过403项逻辑断言、8项发布守卫、20,000组随机报文、编译和Android Lint。没有连接真机，也没有住理生活实际控件树，新增兼容不保证能解决该手机上的问题；无法保证所有广告可跳过或应用不会自行跳转。更新后重新打开住理生活，如仍等待，请查看最近跳过诊断中的“关键结果”“最近状态”“点击目标”和“本次点击”。

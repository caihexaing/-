# 净屏 v0.4.29 · 修复截图 OCR 永远等不到第二帧（构建35）
- 识别用的截图从 1600px 缩到 1100px，中文模型在无障碍服务连上时就预先加载，实测「截屏+识别」从 580–1142ms 降到 323–923ms。
- 读到广告标识后**第一次识别到「跳过」就点**，不再等第二帧确认；课程表这类「跳过」不在右上角、又没倒计时的模板，点击时间从 4.6–7.3 秒降到 2.5–2.9 秒。
- 中文识别器不再和拉丁识别器并跑：中文先跑，只有没读到跳过时才补跑拉丁，一次识别耗时少一半。
- 坐标触摸若在 1.5 秒内没有引起界面变化，会**在同一位置补发一次**（每次开屏最多一次），而不是直接记一次失效；实测天猫/淘宝 H5 模板的清除率从约 2/5 提升到 12/14。

- 住理生活实机诊断：OCR 能读到“跳过”，但一直停在“跳过位置不满足安全条件，未触摸”。真相不是尺寸被拒——几何检查一直通过（29.1dp × 10.0dp），而是**两帧确认等不到**：实测相邻两帧间隔 928ms～6960ms，而确认窗口只有 1400ms，于是每次都重置基准，永远不确认。
- 修复一：两帧确认窗口按真实截图节奏放宽（帧间隔上限 1400ms → 4000ms，总跨度 4000ms → 9000ms），几何、位置容差、点击前复核全部不变。
- 修复二：前两帧固定用快速节奏截图；一旦读到跳过文字，本次开屏也改用快速节奏，不再被 2.5 秒探测限流拖过广告时长。
- 修复三：零位移 50ms 的坐标触摸会被这类 H5 广告丢弃，改用 1px 位移 + 80ms 的短触摸，真机确认可关闭。
- 已用“广告是否仍在屏”做真机判定：vivo V2307A / Android 16 上该模板 4/4 次冷启动广告均被清除并落地应用内容。
- 诊断面板新增的仍是纯几何数字（宽高、帧间隔、触摸坐标），不保存也不上传识别到的文字。
# 净屏 v0.4.28 · 公开点击被忽略时改用坐标触摸（构建34）

- 住理生活实机诊断：开屏广告的“跳过 3”是原生可点击文字，系统报告点击成功，但广告不动；同一位置改用坐标触摸可立即关闭。部分广告 SDK 会声明可点击却静默忽略无障碍点击。
- 新增：一次点击后同一个跳过控件仍然可读，即判定公开点击无效，此时对同一文字中心补一次坐标触摸，每次启动最多补一次。
- 补触摸前复核：控件仍是明确的跳过文字（含倒计时或“跳过广告”）、位置仍在此前点击时记录的矩形内、前台包名与窗口未变、未开启屏幕放大、该应用未关闭坐标触摸、未因两次无效触摸自动停用。
- 真机验证：vivo V2307A / Android 16 连续 5 次冷启动全部跳过广告并落地应用首页，诊断记录“坐标触摸后界面已变化”。
- 仍需在更多广告模板上观察；坐标触摸是兜底手段，若出现误跳请在应用内关闭“允许坐标触摸”。
# 净屏 v0.4.27 · 自绘开屏按钮本机 OCR 兜底（构建33）

- 控件树读不到跳过文字时，可选本机截图 OCR 识别自绘按钮；离线模型随 APK 打包，不依赖首次联网下载。

- Android 8/9 保留原有控件树方案；截图 OCR 需要 Android 11 及以上。APK 体积因捆绑中文和拉丁识别模型增加。
- 安装包支持 ARM 32/64 位安卓手机；不再包含 x86 模拟器原生库以控制下载体积。

# 净屏 v0.4.19 · 开屏跳过稳定性修复（构建25）

- 识别到跳过控件后，在确认控件位置稳定期间将复扫间隔缩短至100ms，降低短暂按钮被漏掉的概率；本次进入仍只允许一次点击，不会补点。

# 净屏 v0.4.18 · 可选 SNI 增强过滤（构建24）

- 新增实验性 SNI 开关。开启后，仅已配置网络过滤的应用使用本机完整 IPv4/IPv6 隧道；本机 SOCKS5 转发器在建立 TCP/443 连接前检查可见 SNI，并使用现有域名规则阻断匹配主机。
- 阻止所选应用的 UDP/443，尝试让支持的应用回退到 TCP/HTTPS；部分应用可能无法回退或联网变慢。默认关闭，需在“设置 → 防护方式与网络”确认开启。
- SNI 不解密 HTTPS；ECH、DoH、直连 IP、缓存及同域广告仍可能绕过。保留 987 条 DNS 拦截规则和 196 条精确主机例外。
- 使用 HevSocks5Tunnel 2.19.3 AAR（MIT），随 APK 提供许可文本；涵盖 arm64-v8a、armeabi-v7a、x86_64 和 x86。
- 基础模式继续支持 Android 8.0+；实验性 SNI 模式要求 Android 10+。

本版没有启用在线规则更新。SNI 模式需在真机上验证目标应用的兼容性，不能承诺开屏广告都会消失。

# 净屏 v0.4.17 · 移动广告域名规则扩充（构建23）

本版没有改变 VPN 路由方式和开屏跳过逻辑。规则只随 APK 更新，尚未启用在线规则更新。

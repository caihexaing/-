# 净屏 v0.4.2

- 修复旧版可能长时间显示“下载已排队、0%”的问题：移除系统下载队列依赖，改用独立前台服务直连下载。
- 主线路超时或失败后，自动尝试同仓库的官方备用 APK 地址，无需跳转浏览器。
- 显示真实连接、线路切换、下载字节、百分比和速度；连接/读取超时各 8 秒，单次任务最多 65 秒，不再无限等待。
- 支持收起后继续、取消和失败重试，保留文件 SHA-256、包名、版本及签名校验；错误页面不会被当成安装包。
- 升级后清理旧版未完成的系统下载任务；保留全窗口开屏跳过。

旧版若卡在系统下载队列，需先手动覆盖安装本版一次，之后使用新的应用内下载器。校园网同时阻断 GitHub 主/备用地址时仍须换网络，不能保证所有网络都可下载。

已通过编译、Android Lint、223 项逻辑检查及 20,000 组随机报文。尚无连接的 iQOO 12 真机，校园网下的后台下载和系统安装交互仍待设备验证。

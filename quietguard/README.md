# 净屏 QuietGuard 0.4.13（构建19）

本机 DNS 域名过滤和开屏按钮辅助跳过工具。不能保证消除全部广告，不保证开屏零延迟。

## 使用

1. 首次安装不选择任何应用。先搜索并打开少量常用应用开关。保守模式默认让新开启应用仅开屏跳过，不干预网络；已有选择和兼容方式保留。
2. “开屏跳过设置”始终打开设置面板，阅读屏幕读取与点击风险后可授权或进入系统无障碍设置。连接服务不会自动改变暂停/恢复开关。
3. 首页“暂停防护”保留选择并立即停止两种处理；“恢复防护”按保留选择重新启用。“一键关闭”清空全部选择，兼容选项保留。
4. 一键开启前显示新增和网络过滤数量；系统应用不批量新增。银行、聊天、网盘等应用异常时，点首页“应用异常”选择并豁免。已豁免应用不会被批量开启覆盖，解除豁免不会自动开启。
5. 已选范围分为仅跳过和网络+跳过，实际网络连接数另列；列表显示数受搜索与筛选影响。运行计数可展开，但规则命中/点击请求不等于广告清除数。
6. 在设置中检查更新，APP内显示检查结果和下载进度。安装由系统确认。手动同意检查不自动开启后台检查，可单独开启自动检查。

## 权限与隐私

无需Root。网络过滤需要系统VPN授权，会与其他VPN互斥。无障碍具备较广的屏幕控件读取与点击能力，纯跳过/文字定位兼容存在误点广告、教程或登录引导的风险。首次开启前说明，可随时暂停、豁免或在系统设置撤销授权。不自动索取电脑授权。

应用列表、设置和固定诊断记录只保存在本机。不解密HTTPS、不保存上传界面文字或截图。公共DNS收到未拦截域名，传统DNS未加密；检查和下载连接GitHub，服务器会收到常规连接信息，不上传应用列表。

## 限制

直接IP、DoH、严格私人DNS、同域内容和缓存可能绕过过滤。规则只处理支持的UDP DNS，尚未接入远程规则运行时。APK沿用兼容签名的调试构建；不得描述为生产加固版本。

## 构建和检查

JDK17、Android SDK36、Build Tools36.0.0。设置本机SDK路径，执行：

```powershell
.\gradlew.bat :app:assembleDebug :app:lintDebug
.\test-core.ps1
python -m unittest discover -s tools/rules -p 'test_*.py' -v
```

代码/CI不包含本机路径或私钥。状态修复与验收范围见 docs/control-and-privacy-design.md。

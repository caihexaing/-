# 净屏 QuietGuard 0.4.24（构建30）

本机 DNS 域名过滤和开屏按钮辅助跳过工具。不能保证消除全部广告，不保证开屏零延迟。

0.4.24对有倒计时的开屏按钮等到最后一秒，再对经过核验的独立跳过区域尝试一次系统按钮动作；倒计时更早时不会点击。

## 使用

设置按权限、豁免、防护网络、更新、帮助分组，每项保留一个主要入口。首页展开区仅展示状态统计。

首页顶部默认收起，保留主状态和暂停/恢复；点“展开”查看详情，点“收起”释放列表空间。展开状态会记住，详情可单独滚动。

1. 首次安装不选择任何应用。先搜索并打开少量常用应用开关。保守模式默认让新开启应用仅开屏跳过，不干预网络；已有选择和兼容方式保留。
2. “设置 → 开屏跳过与权限”打开设置面板，阅读屏幕读取与点击风险后可授权或进入系统无障碍设置。连接服务不会自动改变暂停/恢复开关。
3. 首页“暂停防护”保留选择并立即停止两种处理；“恢复防护”按保留选择重新启用。“一键关闭”经确认后清空全部选择，兼容选项保留。
4. 一键开启前显示新增和网络过滤数量；系统应用不批量新增。银行、聊天、网盘等应用异常时，在“设置 → 应用豁免”选择并豁免。已豁免应用不会被批量开启覆盖，解除豁免不会自动开启。豁免列表优先显示已开启的普通应用，系统应用靠后。
5. 已选范围分为仅跳过和网络+跳过，实际网络连接数另列；列表显示数受搜索与筛选影响。展开首页状态可查看运行计数，但规则命中/点击请求不等于广告清除数。
6. 在设置中检查更新，APP内显示检查结果和下载进度。安装由系统确认。手动同意检查不自动开启后台检查，可单独开启自动检查。

## 权限与隐私

无需Root。网络过滤需要系统VPN授权，会与其他VPN互斥。无障碍具备较广的屏幕控件读取与点击能力；纯“跳过”兼容可能误认教程入口，已移除坐标触摸，按钮未公开点击动作时可能无法自动跳过。首次开启前说明，可随时暂停、豁免或在系统设置撤销授权。不自动索取电脑授权。

应用列表、设置和固定诊断记录只保存在本机。不解密HTTPS、不保存上传界面文字或截图。公共DNS收到未拦截域名，传统DNS未加密；检查和下载连接GitHub，服务器会收到常规连接信息，不上传应用列表。

## 规则与限制

本版内置 987 条 DNS 域名拦截规则，并附带 196 条精确主机例外。规则源、转换方法和许可证见 `tools/rules/RULE-SOURCES.md`。规则随 APK 更新，尚未接入在线规则更新。

可选实验性 SNI 增强模式（Android 10+）使用本机完整隧道检查所选应用 TCP/443 的可见 SNI；它不解密 HTTPS，并阻止 UDP/443尝试触发 HTTP/3 回退。启用前会展示兼容性提示。Android 8–9 继续使用基础 DNS 模式。第三方隧道组件及许可证见 `docs/sni-enhanced-mode.md`。

直接IP、DoH、严格私人DNS、ECH、同域内容和缓存可能绕过过滤。规则数量有限，只能阻止命中规则的域名请求，不能直接删除广告SDK或控件。UDP/443 阻止可能使部分应用无法回退到 TCP。开屏依赖独立无障碍辅助跳过，无法识别时可能仍需等待广告结束。APK沿用兼容签名的调试构建；不得描述为生产加固版本。

## 构建和检查

JDK17、Android SDK36、Build Tools36.0.0。设置本机SDK路径，执行：

```powershell
.\gradlew.bat :app:assembleDebug :app:lintDebug
.\test-core.ps1
python -m unittest discover -s tools/rules -p 'test_*.py' -v
```

代码/CI不包含本机路径或私钥。状态修复与验收范围见 docs/control-and-privacy-design.md。

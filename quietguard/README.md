# 净屏 QuietGuard 0.4.10（构建16，缩短开屏识别等待）

首页应用数量右侧新增“一键开启”，一次开启扫描到的全部普通应用并启动防护。搜索词、仅已开启筛选和系统应用显示开关不限制批量范围。系统应用不批量新增；已手动开启的系统应用以及各应用仅跳过、纯跳过、文字定位兼容设置全部保留。首次使用仍需确认系统VPN和无障碍授权；可选电脑一次授权后，净屏按钮可直接开启自身无障碍服务，无需持续插USB，见[快捷开启说明](docs/accessibility-quick-setup-design.md)。

住理生活出现开屏等待/短暂黑屏时，可长按列表中的住理生活 → 选择“仅开屏跳过（启动兼容）” → 保存 → 退出并重新进入。该方式不阻断此应用的域名请求，通过可读取的跳过按钮关闭开屏广告；广告可能短暂出现，页面内其他广告不再使用域名过滤。默认仍是网络过滤+开屏跳过，不自动更改现有选择。用户已实测0.4.3广告消失，但开发机没有设备日志，尚不能确认黑屏的具体原因或本版的真机改善。

免 Root 的 Android 按应用 DNS 广告过滤和开屏自动跳过测试版，Android 8.0 及以上。不能保证消除其他应用内的所有广告。

0.4.10缩短进入应用前3秒的识别扫描间隔，并减少纯跳过兼容下的额外广告标识查询；保留350毫秒位置稳定确认和一次操作限制。此次未连接手机，不能保证提速幅度或零延迟，见[提速设计](docs/splash-latency-design.md)。

## 使用

1. 安装 APK，允许安装来源；本文件为开发测试版签名，适合个人试用。
2. 首次打开会读取当前用户可见的已安装应用。搜索框支持名称和包名；默认隐藏未选择的系统应用。
3. 打开需要过滤的应用右侧开关，阅读说明并同意 Android VPN 授权。顶部应显示“正在过滤 N 个应用”。可继续打开其他应用的开关。
4. 点击“开启开屏广告跳过”，阅读界面访问和点击用途说明，同意后开启“净屏 · 开屏广告跳过”：已做电脑一次授权时直接设置，无需进入系统设置；未授权时仍需在系统设置手动开启。返回首页确认“开屏跳过：已就绪”，再关闭并重新打开目标应用。仅打开应用开关但未授予无障碍权限，仍只有 DNS 过滤。
5. 首次启动可允许通知权限，便于查看状态。首页“暂停防护”和通知“暂停全部防护”同时暂停网络过滤与自动跳过。系统 VPN 设置只关闭 VPN，已经授权的无障碍跳过可独立运行。关闭某个应用的开关会同时停用该应用的两种处理。
6. 设置中可切换公共 DNS，填写域名例外。例外优先，并包含子域名。
   长按单个应用可选择网络过滤+开屏跳过，或仅开屏跳过。全部应用只跳过时无需VPN；混合选择时，VPN只处理需要网络过滤的应用。原有纯跳过兼容独立保留，开启后也可能跳过该应用教程。
7. 设置中点击“检查更新”，同意连接 GitHub 后会启用每天一次的启动检查；可关闭自动检查。点击“立即更新”在净屏内下载，显示进度、百分比、已下载大小和速度，可取消或收起。完成校验后点击“安装更新”，由系统确认安装。首次需允许净屏安装应用，返回后继续。0.4.2构建8及之后会在检查和下载时自动暂时断开净屏自己的 VPN，结束、失败或取消后按原状态恢复。更早版本首次升级时，请先手动暂停净屏 VPN，以避免下载受影响。

后续发布流程与签名说明见 [GitHub 更新说明](docs/github-updates.md)。仅识别 quietguard-vX.Y.Z 的正式 Release，忽略此仓库其他应用的版本。

## 能力和限制

- 使用 Android VpnService 的应用允许列表，只将选中且使用网络过滤的应用的系统 UDP DNS 请求引入本地隧道；仅跳过应用排除在VPN之外，业务流量保持直连。不修改其他应用，不读取 HTTPS 内容。
- 开屏跳过使用系统无障碍服务，仅在选中应用进入前台后15秒内，在整个应用窗口内识别尺寸受限且公开点击动作的跳过控件。文字自身无动作时最多核对两层外层按钮，要求其完整内容只有跳过文字、倒计时或短广告标识，并且紧贴文字、没有其他交互入口。默认要求倒计时、广告标识或按钮自身明确写明“跳过广告/关闭广告/Skip Ad”。纯跳过兼容仍需单独开启。文字与描述冲突、非当前应用/窗口、过大的容器或读取不完整都不执行。默认使用核对后的按钮ACTION_CLICK，不进行盲目父容器点击、不执行全局返回。用户为单个应用主动开启文字定位点击后，在限定条件下允许一次文字中心触摸。
- 独立工作线程先按文字查找相关控件；进入已选应用前3秒，两次扫描之间从上次完成后至少等待200ms，之后恢复500ms；同包事件不延长加速期，窗口事件不能绕过间隔。必要时最多每2500ms补一次广度遍历，最多1200节点、32层、24候选，在节点调用之间检查80ms预算。小按钮完整核对最多12节点、深度3、节点调用间80ms预算，每轮候选核对另有120ms预算，点击前再核对一次。单次系统调用仍可能耗时。每次进入只允许一次操作请求：语义点击和文字定位触摸共用额度，系统接受、拒绝或抛错后都不补点；接受后仅观察原控件。原按钮不再可读不证明广告消失。纯图片、自绘或未开放直接点击动作的按钮不保证有效。
- 无障碍功能需用户同意；默认通过系统设置授权，可选经电脑一次授予安全设置写权限后由APP按钮开启自身服务。此权限不会随普通安装自动获得，卸载或撤权后可能需重授。界面文字仅本机短暂处理，不保存、不上传；先读取当前窗口包名，只对选中窗口做页面搜索；目标按钮子树逐节点核对所属包与窗口。本机仅保留最近目标包、检测时间、节点数、是否曾读到跳过/广告标识和固定原因说明，可在设置中查看、清除。Android 无障碍服务本身拥有广泛能力，可随时在系统设置中关闭。
- 内置精选域名清单在 app/src/main/assets/ad-domains.txt。它是首版种子规则，不是全网广告识别库；没有自动下载与更新功能。
- 域名方式可能漏拦或误拦。缓存、直接 IP、应用自带加密 DNS、与正文共用域名的广告无法可靠过滤。不能保证清除全部广告，广告占位也可能保留。
- 本版没有 TCP DNS 隧道。需要 TCP 回退的解析可能失败。系统严格私人 DNS 请关闭；若应用无法联网，先关闭该应用开关恢复，再检查 DNS 或设置域名例外。
- 网络过滤会占用 Android VPN 通道，与其他 VPN/加速器/代理 VPN 模式互斥。VPN 未提供通用开机自启；本版会记录更新前的运行意图，并在更新下载结束、安装替换广播或返回 APP 时尝试恢复，其他进程被杀情形不承诺自动恢复；无障碍服务由系统管理，若系统重新连接且防护仍开启，自动跳过可能恢复。首页分别显示两种服务的真实状态。部分厂商省电策略可能停止服务。
- 开关选择、域名例外保存在本机；不上传应用列表、不保存访问域名日志、不含分析 SDK。未被拦截的域名会发送给设置选定的公共 DNS；传统 DNS 传输未加密，应按自己的隐私需求选择。用户开启版本检查后会读取 GitHub 仓库中的公开版本文件；GitHub 会收到常规网络连接信息，不会收到已安装应用列表。
- 已选应用变化后重建 VPN，DNS 计数归零。“规则命中”是命中广告/追踪域名的 DNS 请求次数，重复重试会重复计数；“转发失败”仅代表 DNS 转发错误，不表示广告漏拦。“点击操作”只是系统接受的控件点击或提交的定位触摸请求，在本机累计；触摸完成回调也不能证明广告已消失。没有“清除广告数量”的统计。读到应用列表不代表检测出该应用内的所有广告。
- QUERY_ALL_PACKAGES 用于本机应用选择；Android 与厂商限制仍可能使其他用户空间、工作资料等应用不可见。发布商店前需要独立评估商店权限与 VPN 相关政策。
- 沿用 0.4.1 的 Android DownloadManager 应用内下载和真实进度，无需浏览器或存储访问权限。检查前暂时关闭本 APP 的 VPN 隧道，检查结束恢复；下载前再次暂停，后台完成广播、失败、取消都会结束暂停。下载连续 60 秒没有进展时取消并恢复，不会长期关闭防护等待。检查的暂停最多 30 秒。原本关闭的 VPN 保持关闭，更新中手动暂停防护优先，不自动重启；只控制净屏自己的 VPN。安装前再次暂时断开 VPN 并保存运行意图，安装替换后尝试恢复；若系统限制后台启动，返回 APP 重试；VPN 授权失效或被其他软件替换时，显示恢复入口并要求系统授权，不抢占其他 VPN。
- 下载完成后校验 GitHub 版本信息中的 SHA-256，再核对 APK 包名、版本号和签名；只将校验通过的安装包复制到应用私有缓存，并临时授予系统安装程序读取权限。损坏、错版本或签名不一致的文件不会进入安装流程。系统安装阶段使用系统界面，不提供虚构的安装百分比或静默安装。

## 一键开启

点击首页应用数量旁的“一键开启”，新增选择所有已扫描、启用且非系统的普通应用，并调用一次现有防护启动流程。扫描中或读取失败时按钮不可用，避免按不完整列表操作；没有普通应用时提示刷新。重复点击不会重复添加。不会自动给新应用开启纯跳过或文字定位兼容，已有成功配置保持原样。后续新安装的应用需刷新后再点一次。

## 住理生活文字定位兼容

更新到0.4.7后，长按已开启的住理生活 → 防护方式 → 勾选“文字定位点击（兼容，可能误触）” → 保存，再重新打开住理生活。旧版默认行为保持，其他应用不自动开启。如果诊断显示系统未授予定位触摸能力，到系统无障碍中关闭后重新开启净屏，再返回确认已就绪。

只支持唯一、明确的小尺寸跳过文字叶子，两个扫描间隔至少350ms、至多1300ms；必须同一节点、包名、窗口和完全相同的文字边界及窗口边界。倒计时可变化，但文字和描述不得出现推广语义。点击前再刷新并核对前台、选择、开关、锁屏和启动窗口。系统放大开启时放弃。坐标仅暂存在内存，不写入配置或诊断。

界面在最后核对后变化、悬浮层、错误或误导性的控件信息仍可能使触摸命中广告，不能保证零误触；发现误跳请关闭该兼容选项。它不会点击大容器，也不会在发过控件点击后再发手势。请求被取消或拒绝也消耗本次额度。默认关闭，所有应用必须分别选择。

## 验证

已执行核心JVM报文规则（91项及20,000组随机报文）、版本（15项）、开屏匹配/单动作（100项）、运行时限频/路由（44项）、语义按钮树/诊断（105项）、文字定位稳定性/几何/显式开关/共享额度（48项）、更新完整性（30项）、VPN更新状态（31项），新增无障碍选择保留测试16项，合计480项；另有13项源码发布守卫。APK通过编译与Android Lint。发布核对手势能力、唯一触摸入口、兼容签名、版本和更新源哈希。

0.4.9已连接iQOO 12 / Android 16：完成覆盖安装、一次安全设置写权限授权、APP按钮开启并绑定无障碍、重复点击不改变选择，102个已选应用及兼容设置保持。未重新验证实际广告跳过、物理拔线、重启、VPN路由、下载管理器和厂商后台兼容性。

建议真机流程：选择一个应用 → 确认 VPN 状态 → 打开普通页面验证联网 → 查看 DNS 请求计数是否增长 → 对比广告是否减少 → 关闭开关并验证联网恢复 → 用另一个 VPN 替换后检查净屏显示已停止。失败请求持续增长时切换上游 DNS 或停止过滤。

开屏流程：授权无障碍 → 返回首页确认已就绪 → 选中目标应用 → 重新进入 → 对照实际广告与设置中的最近跳过诊断。WakeUp验证见 docs/wakeup-device-check.md。关闭开关或暂停防护、未选择应用和锁屏时不得点击；兼容关闭时，普通无广告标识的教程跳过不得点击。兼容开启后可能跳过该应用教程。点击次数增加但广告仍在，仍应视为未解决。

更新流程：先覆盖安装构建 8 → 开启净屏 VPN → 检查更新时核对 VPN 临时断开并恢复 → 点击下载时再次确认 VPN 暂时断开 → 核对真实进度 → 收起/旋转/后台后返回 → 下载完成后核对 VPN 恢复 → 安装新版本 → 核对替换安装后恢复。分别检查取消、失败、60 秒无进展、原本 VPN 关闭、更新中手动暂停、系统杀进程、授权被其他 VPN 替换等情形。首次从旧版升级不能让旧版获得新代码，必要时需手动关闭 VPN 后安装一次。

## 构建

使用 JDK 17、Android SDK Platform 36、Build Tools 36.0.0、Gradle 8.11.1 和 AGP 8.9.2。设置 ANDROID_HOME 或在本机创建 local.properties 指向 SDK。

```powershell
.\gradlew.bat :app:assembleDebug :app:lintDebug
.\test-core.ps1
```

源代码包不包含本机 SDK 路径、构建缓存或私钥。debug 构建会使用构建机器的调试密钥；换机器重建后签名可能不同，不能直接覆盖已安装版本。

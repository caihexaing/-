# 净屏 QuietGuard 0.5.0（构建36）

本机 DNS 域名过滤和开屏按钮辅助跳过工具。不能保证消除全部广告，不保证开屏零延迟。

0.5.0把 DNS 规则库从 987 条扩到 280,602 条域名，并新增 CNAME 别名检查：广告 SDK 用自有域名做 CNAME 指向广告域时，DNS 应答的最终别名落在拦截清单也会按 NXDOMAIN 处理，这是此前绕过 DNS 过滤最常见的形式。规则由四份 DNS 专用列表离线编译，编译时会拒绝任何会让微信、支付宝、淘宝、京东、百度、B站、抖音等主流程域名被拦的规则集。

同一版本补齐了另外几条真实存在、此前完全敞开的绕过通道：应用自带的 DoH/HTTPDNS 域名（`dns.google`、`doh.pub`、`httpdns.*` 等）按广告同样拦截；公共解析器的 IP（`1.1.1.1`、`8.8.8.8`、`223.5.5.5` 等 20 个）单独路由进隧道，明文 UDP/53 照常按规则过滤，加密的 DoH/DoT 因内容不可见而直接拒绝并回 RST，让应用快速回退到系统解析器而不是卡住等超时；上游回 TC 位时由净屏自己改用 TCP/53 取完整应答，不再让整个域名解析失败；SNI 模式补上 TCP/80 的 Host 头检查和任意端口的 CONNECT 目标名检查。

0.4.28修正常见开屏广告“点击成功但广告不动”：部分 SDK 的可点击跳过文字会静默忽略无障碍点击，此时对同一文字中心补一次坐标触摸，每次启动最多一次，并复核位置、前台窗口与该应用开关。0.4.27增加可选的本机离线 OCR 截图兜底：控件树读不到时，在已选应用启动阶段识别两帧稳定的明确跳过文字，再最多触摸一次；截图与文字不保存、不上传。

## 使用

设置按权限、豁免、防护网络、更新、帮助分组，每项保留一个主要入口。首页展开区仅展示状态统计。

首页顶部默认收起，保留主状态和暂停/恢复；点“展开”查看详情，点“收起”释放列表空间。展开状态会记住，详情可单独滚动。

1. 首次安装不选择任何应用。先搜索并打开少量常用应用开关。保守模式默认让新开启应用仅开屏跳过，不干预网络；已有选择和兼容方式保留。
2. “设置 → 开屏跳过与权限”打开设置面板，阅读屏幕读取与点击风险后可授权或进入系统无障碍设置。连接服务不会自动改变暂停/恢复开关。
3. 首页“暂停防护”保留选择并立即停止两种处理；“恢复防护”按保留选择重新启用。“一键关闭”经确认后清空全部选择，兼容选项保留。
4. 一键开启前显示新增和网络过滤数量；系统应用不批量新增。银行、聊天、网盘等应用异常时，在“设置 → 应用豁免”选择并豁免。已豁免应用不会被批量开启覆盖，解除豁免不会自动开启。豁免列表优先显示已开启的普通应用，系统应用靠后。
5. 已选范围分为仅跳过和网络+跳过，实际网络连接数另列；列表显示数受搜索与筛选影响。展开首页状态可查看运行计数，但规则命中/点击请求不等于广告清除数。
6. 在设置中检查更新，APP内显示检查结果和下载进度。安装由系统确认。手动同意检查不自动开启后台检查，可单独开启自动检查。

## 权限与隐私

无需Root。网络过滤需要系统VPN授权，会与其他VPN互斥。无障碍具备较广的屏幕控件读取与点击能力；纯“跳过”兼容可能误认教程入口，已移除坐标触摸，按钮未公开点击动作时可能无法自动跳过。首次开启前说明，可随时暂停、豁免或在系统设置撤销授权。不自动索取电脑授权。

应用列表、设置和固定诊断记录只保存在本机。不解密HTTPS、不保存上传界面文字或截图。公共DNS收到未拦截域名，传统DNS未加密；检查和下载连接GitHub，服务器会收到常规连接信息，不上传应用列表。

## 规则与限制

本版内置约 28 万条 DNS 域名拦截规则（280,602 条）与 339 条主机例外，合并自 AdGuard DNS、OISD、anti-AD、AdRules DNS 四份 DNS 专用过滤列表与净屏自建清单。DNS 应答里的 CNAME 别名也会比对拦截清单，用于对付用自有域名伪装、把请求转指广告域的 SDK。规则源、转换方法和许可证见 `tools/rules/RULE-SOURCES.md`。规则随 APK 更新，尚未接入在线规则更新。

可选实验性 SNI 增强模式（Android 10+）使用本机完整隧道检查所选应用 TCP/443 的可见 SNI；它不解密 HTTPS，并阻止 UDP/443尝试触发 HTTP/3 回退。启用前会展示兼容性提示。Android 8–9 继续使用基础 DNS 模式。第三方隧道组件及许可证见 `docs/sni-enhanced-mode.md`。

直接IP、严格私人DNS、ECH、同域内容和缓存可能绕过过滤。默认开启的“阻断应用自带加密 DNS”会把应用内建解析器的域名与 IP 一并堵住，但若某个应用写死了解析器且无回退，会表现为解析失败 —— 此时先在设置里关掉该项再试。广告与业务内容混用同一域名、或直接由 IP 提供的广告也无法在网络层区分；DNS 过滤能拦住广告素材与接口请求，但不保证清除每一个广告位，也不能直接删除广告SDK或控件。UDP/443 阻止可能使部分应用无法回退到 TCP。开屏依赖独立无障碍辅助跳过，无法识别时可能仍需等待广告结束。APK沿用兼容签名的调试构建；不得描述为生产加固版本。

## 构建和检查

JDK17、Android SDK36、Build Tools36.0.0。设置本机SDK路径，执行：

```powershell
.\gradlew.bat :app:assembleDebug :app:lintDebug
.\test-core.ps1
python -m unittest discover -s tools/rules -p 'test_*.py' -v
```

代码/CI不包含本机路径或私钥。状态修复与验收范围见 docs/control-and-privacy-design.md。

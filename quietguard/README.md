# 净屏 QuietGuard 0.4.2（构建 8，VPN 自动暂停/恢复修订）

免 Root 的 Android 按应用 DNS 广告过滤和开屏自动跳过测试版，Android 8.0 及以上。不能保证消除其他应用内的所有广告。

## 使用

1. 安装 APK，允许安装来源；本文件为开发测试版签名，适合个人试用。
2. 首次打开会读取当前用户可见的已安装应用。搜索框支持名称和包名；默认隐藏未选择的系统应用。
3. 打开需要过滤的应用右侧开关，阅读说明并同意 Android VPN 授权。顶部应显示“正在过滤 N 个应用”。可继续打开其他应用的开关。
4. 点击“开启开屏广告跳过”，阅读界面访问和点击用途说明，同意后前往系统无障碍设置，手动开启“净屏 · 开屏广告跳过”。返回首页确认“开屏跳过：已就绪”，再关闭并重新打开目标应用。仅打开应用开关但未授予无障碍权限，仍只有 DNS 过滤。
5. 首次启动可允许通知权限，便于查看状态。首页“暂停防护”和通知“暂停全部防护”同时暂停网络过滤与自动跳过。系统 VPN 设置只关闭 VPN，已经授权的无障碍跳过可独立运行。关闭某个应用的开关会同时停用该应用的两种处理。
6. 设置中可切换公共 DNS，填写域名例外。例外优先，并包含子域名。
7. 设置中点击“检查更新”，同意连接 GitHub 后会启用每天一次的启动检查；可关闭自动检查。新版本显示发布说明，点击“立即更新”在净屏内下载，弹窗显示真实进度条、百分比、已下载大小和速度，可取消或收起。完成校验后点击“安装更新”，由系统确认安装。首次需在系统设置中允许净屏安装应用，返回后继续。本版检查和下载时自动暂时断开净屏自己的 VPN，结束、失败或取消后按原状态恢复。需要先覆盖安装本修订版一次，之后的更新才能执行新的暂停/恢复流程。旧版 0.4.2（构建 7）的检查器不识别同名修订版，需要手动安装。

后续发布流程与签名说明见 [GitHub 更新说明](docs/github-updates.md)。仅识别 quietguard-vX.Y.Z 的正式 Release，忽略此仓库其他应用的版本。

## 能力和限制

- 使用 Android VpnService 的应用允许列表，只将选中应用的系统 UDP DNS 请求引入本地隧道；业务流量保持直连。不修改其他应用，不读取 HTTPS 内容。
- 开屏跳过使用系统无障碍服务，仅在选中应用进入前台后 15 秒内，在整个应用窗口内识别尺寸受限的跳过控件。要求明确的跳过文字以及倒计时或广告标识，优先控件点击；必要时仅点击刚识别到的跳过控件中心，不盲点截图位置。普通页面、推广“启动”和任意“×”按钮不会被当作跳过目标。
- 每次进入目标包只尝试最多两次，系统接受点击请求后停止。广告可能短暂出现；纯图片/视频画布、未开放的控件、不可跳过广告、页面中其他广告等不保证有效。截图只能证明按钮外观，不能证明真实控件可识别或实际已跳过。
- 无障碍功能必须由用户在系统设置中手动授权。界面内容仅本机短暂处理，不保存、不上传；只读取非选中窗口的包名以取消操作，不遍历非选中窗口的内容。Android 无障碍服务本身拥有广泛能力，可随时在系统设置中关闭。
- 内置精选域名清单在 app/src/main/assets/ad-domains.txt。它是首版种子规则，不是全网广告识别库；没有自动下载与更新功能。
- 域名方式可能漏拦或误拦。缓存、直接 IP、应用自带加密 DNS、与正文共用域名的广告无法可靠过滤。不能保证清除全部广告，广告占位也可能保留。
- 本版没有 TCP DNS 隧道。需要 TCP 回退的解析可能失败。系统严格私人 DNS 请关闭；若应用无法联网，先关闭该应用开关恢复，再检查 DNS 或设置域名例外。
- 网络过滤会占用 Android VPN 通道，与其他 VPN/加速器/代理 VPN 模式互斥。VPN 未提供通用开机自启；本版会记录更新前的运行意图，并在更新下载结束、安装替换广播或返回 APP 时尝试恢复，其他进程被杀情形不承诺自动恢复；无障碍服务由系统管理，若系统重新连接且防护仍开启，自动跳过可能恢复。首页分别显示两种服务的真实状态。部分厂商省电策略可能停止服务。
- 开关选择、域名例外保存在本机；不上传应用列表、不保存访问域名日志、不含分析 SDK。未被拦截的域名会发送给设置选定的公共 DNS；传统 DNS 传输未加密，应按自己的隐私需求选择。用户开启版本检查后会读取 GitHub 仓库中的公开版本文件；GitHub 会收到常规网络连接信息，不会收到已安装应用列表。
- 已选应用变化后重建 VPN，DNS 计数归零。“规则命中”是命中广告/追踪域名的 DNS 请求次数，重复重试会重复计数；“转发失败”仅代表 DNS 转发错误，不表示广告漏拦。“点击操作”只是系统接受的跳过点击请求，在本机累计，不能证明广告已消失。没有“清除广告数量”的统计。读到应用列表不代表检测出该应用内的所有广告。
- QUERY_ALL_PACKAGES 用于本机应用选择；Android 与厂商限制仍可能使其他用户空间、工作资料等应用不可见。发布商店前需要独立评估商店权限与 VPN 相关政策。
- 沿用 0.4.1 的 Android DownloadManager 应用内下载和真实进度，无需浏览器或存储访问权限。检查前暂时关闭本 APP 的 VPN 隧道，检查结束恢复；下载前再次暂停，后台完成广播、失败、取消都会结束暂停。下载连续 60 秒没有进展时取消并恢复，不会长期关闭防护等待。检查的暂停最多 30 秒。原本关闭的 VPN 保持关闭，更新中手动暂停防护优先，不自动重启；只控制净屏自己的 VPN。安装前再次暂时断开 VPN 并保存运行意图，安装替换后尝试恢复；若系统限制后台启动，返回 APP 重试；VPN 授权失效或被其他软件替换时，显示恢复入口并要求系统授权，不抢占其他 VPN。
- 下载完成后校验 GitHub 版本信息中的 SHA-256，再核对 APK 包名、版本号和签名；只将校验通过的安装包复制到应用私有缓存，并临时授予系统安装程序读取权限。损坏、错版本或签名不一致的文件不会进入安装流程。系统安装阶段使用系统界面，不提供虚构的安装百分比或静默安装。

## 验证

已执行核心 JVM 报文和规则检查（91 项断言及 20,000 组随机报文）、版本检查（15 项）、开屏匹配和误点限制（56 项）、更新完整性/取消/进度/下载地址隔离检查（30 项）、VPN 更新状态机检查（31 项）。测试覆盖左上、右上、中部、底部按钮和窗口偏移，同时拒绝无广告依据的普通跳过控件及超大容器。APK 通过编译与 Android Lint；自动发布流程校验旧版兼容签名。

尚无连接的 Android 真机或模拟器，因此未完成界面渲染、VPN/无障碍授权、实际路由、住理生活真实控件树与点击效果、下载管理器及系统安装交互、厂商后台兼容性测试；安装包为待真机验证的原型。

建议真机流程：选择一个应用 → 确认 VPN 状态 → 打开普通页面验证联网 → 查看 DNS 请求计数是否增长 → 对比广告是否减少 → 关闭开关并验证联网恢复 → 用另一个 VPN 替换后检查净屏显示已停止。失败请求持续增长时切换上游 DNS 或停止过滤。

开屏流程：授权无障碍 → 返回首页确认已就绪 → 选中住理生活 → 重新进入住理生活 → 检查是否点击右上角跳过并进入首页 → 回净屏查看点击次数。关闭开关或暂停防护后应不再自动点击。打开未选择的应用、普通带“跳过”但无广告标识的引导页、锁屏时均不应点击。点击次数增加但广告仍在，仍应视为未解决。

更新流程：先覆盖安装构建 8 → 开启净屏 VPN → 检查更新时核对 VPN 临时断开并恢复 → 点击下载时再次确认 VPN 暂时断开 → 核对真实进度 → 收起/旋转/后台后返回 → 下载完成后核对 VPN 恢复 → 安装新版本 → 核对替换安装后恢复。分别检查取消、失败、60 秒无进展、原本 VPN 关闭、更新中手动暂停、系统杀进程、授权被其他 VPN 替换等情形。首次从旧版升级不能让旧版获得新代码，必要时需手动关闭 VPN 后安装一次。

## 构建

使用 JDK 17、Android SDK Platform 36、Build Tools 36.0.0、Gradle 8.11.1 和 AGP 8.9.2。设置 ANDROID_HOME 或在本机创建 local.properties 指向 SDK。

```powershell
.\gradlew.bat :app:assembleDebug :app:lintDebug
.\test-core.ps1
```

源代码包不包含本机 SDK 路径、构建缓存或私钥。debug 构建会使用构建机器的调试密钥；换机器重建后签名可能不同，不能直接覆盖已安装版本。

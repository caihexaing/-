# 净屏 QuietGuard 0.2.1

免 Root 的 Android 按应用 DNS 广告过滤测试版，Android 8.0 及以上。

## 使用

1. 安装 APK，允许安装来源；本文件为开发测试版签名，适合个人试用。
2. 首次打开会读取当前用户可见的已安装应用。搜索框支持名称和包名；默认隐藏未选择的系统应用。
3. 打开需要过滤的应用右侧开关，阅读说明并同意 Android VPN 授权。顶部应显示“正在过滤 N 个应用”。可继续打开其他应用的开关。
4. 首次启动可允许通知权限，便于查看状态和停止服务。总按钮、通知按钮和系统 VPN 设置均可停止。
5. 设置中可切换公共 DNS，填写域名例外。例外优先，并包含子域名。
6. 设置中点击“检查更新”，同意连接 GitHub 后会启用每天一次的启动检查；可关闭自动检查。新版本显示发布说明，点击后使用浏览器下载，再由系统确认安装。0.1.0 需要手动安装 0.2.1 一次。

后续发布流程与签名说明见 [GitHub 更新说明](docs/github-updates.md)。仅识别 quietguard-vX.Y.Z 的正式 Release，忽略此仓库其他应用的版本。

## 能力和限制

- 使用 Android VpnService 的应用允许列表，只将选中应用的系统 UDP DNS 请求引入本地隧道；业务流量保持直连。不修改其他应用，不读取 HTTPS 内容。
- 内置精选域名清单在 app/src/main/assets/ad-domains.txt。它是首版种子规则，不是全网广告识别库；没有自动下载与更新功能。
- 域名方式可能漏拦或误拦。缓存、直接 IP、应用自带加密 DNS、与正文共用域名的广告无法可靠过滤。不能保证清除全部广告，广告占位也可能保留。
- 本版没有 TCP DNS 隧道。需要 TCP 回退的解析可能失败。系统严格私人 DNS 请关闭；若应用无法联网，先关闭该应用开关恢复，再检查 DNS 或设置域名例外。
- 会占用 Android VPN 通道，与其他 VPN/加速器/代理 VPN 模式互斥。未提供开机自启和进程被杀后的自动恢复，打开界面查看真实运行状态。部分厂商省电策略可能停止服务。
- 开关选择、域名例外保存在本机；不上传应用列表、不保存访问域名日志、不含分析 SDK。未被拦截的域名会发送给设置选定的公共 DNS；传统 DNS 传输未加密，应按自己的隐私需求选择。用户开启版本检查后会读取 GitHub 仓库中的公开版本文件；GitHub 会收到常规网络连接信息，不会收到已安装应用列表。
- 已选应用变化后重建 VPN，计数归零。界面计数是 DNS 请求数量，不是广告数量。读到应用列表不代表检测出该应用内的所有广告。
- QUERY_ALL_PACKAGES 用于本机应用选择；Android 与厂商限制仍可能使其他用户空间、工作资料等应用不可见。发布商店前需要独立评估商店权限与 VPN 相关政策。

## 验证

已执行核心 JVM 报文和规则检查，包括边界匹配、例外优先、响应校验、畸形报文、IPv4 校验和及随机报文测试。APK 通过编译及签名校验。详细最终结果见交付的使用说明。

尚无连接的 Android 真机或模拟器，因此未完成界面渲染、VPN 授权、实际路由、过滤效果、厂商后台兼容性测试；安装包为待真机验证的原型。

建议真机流程：选择一个应用 → 确认 VPN 状态 → 打开普通页面验证联网 → 查看 DNS 请求计数是否增长 → 对比广告是否减少 → 关闭开关并验证联网恢复 → 用另一个 VPN 替换后检查净屏显示已停止。失败请求持续增长时切换上游 DNS 或停止过滤。

## 构建

使用 JDK 17、Android SDK Platform 36、Build Tools 36.0.0、Gradle 8.11.1 和 AGP 8.9.2。设置 ANDROID_HOME 或在本机创建 local.properties 指向 SDK。

```powershell
.\gradlew.bat :app:assembleDebug :app:lintDebug
.\test-core.ps1
```

源代码包不包含本机 SDK 路径、构建缓存或私钥。debug 构建会使用构建机器的调试密钥；换机器重建后签名可能不同，不能直接覆盖已安装版本。

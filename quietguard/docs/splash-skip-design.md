# 0.3.0 开屏跳过设计

用户要求继续实现单个应用开关控制广告防护，重点处理其截图右上角“4s｜跳过”的开屏广告。无需再次确认产品方向，但系统授权由设备用户手动完成。

扩展现有应用开关，同时控制原 DNS 规则过滤与新增无障碍开屏跳过。总开关和通知中的暂停按钮停止两者。VPN 停止或授权被其他 VPN 替换后，自动跳过可以独立运行，界面分别报告两种服务的真实状态。

无障碍使用前在 APK 内说明界面读取、点击、作用范围和隐私，再由用户进入系统设置授权。未授权时不执行。只检查选中应用当前活动窗口，非选中窗口只检查包名并取消；界面内容不持久化、不传出。

进入目标包后只工作 15 秒，不因同包内 Activity 或控件变化续期。在整个应用窗口内识别尺寸受限的“跳过/跳过广告/关闭广告/Skip Ad”明确按钮；必须带倒计时或页面存在明确广告标识。优先执行控件点击、相近且尺寸受限的父控件点击；最后可对刚识别到的跳过控件中心注入手势。不使用截图固定坐标，不点击广告主体、推广“启动”、关闭普通业务页面或整页父容器。锁屏或切出目标应用时停止。

一次启动最多两次尝试，间隔至少 1 秒，系统接受一次点击请求后结束。记录的是点击请求次数，并不把 ACTION_CLICK 返回 true 当成实际广告消失。计数在本地累计；DNS 计数改为请求、规则命中、转发失败，显式标注命中不是广告去除次数。

测试覆盖截图文字和区域、中文/英文控件、分离广告标识、普通跳过、推广按钮、全屏父节点、过期/重复窗口事件、暂停/取消选择。现有 DNS 和版本检查测试保持执行。编译、Lint、CI 发布、线上 APK 签名及校验值验证；当前无真机连接，不声称已验证“住理生活”的真实控件树或实际点击效果。

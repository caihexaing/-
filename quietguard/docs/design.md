# 净屏 0.1 设计与验证计划

2026-11-03；用户已同意免 Root、本地 VPN、按应用控制的首版范围。

原生 Java Android APK，Android 8.0 及以上。安装应用列表在本机读取，可按名称和包名搜索，默认显示用户应用，可显示系统应用。应用选择与域名例外持久化。

VPN 仅捕获选中应用发往虚拟 DNS 的请求；使用受保护的 UDP 套接字向用户选择的上游 DNS 转发，正常业务流量由系统直连。广告域名使用内置人工精选清单，匹配完整域名及其子域名，例外优先。VPN 本身不连接商业远端 VPN，不解密 HTTPS。上游 DNS 仍会收到未拦截域名，传统 DNS 不加密，设置页明确展示。

VPN 由用户确认启动；前台通知可停止。切换应用后重建 VPN；无选中应用时停止，防止空白允许列表变成全机 VPN。处理撤销、启动失败、网络变化、进程终止后的状态，默认不自动重启。计数仅为 DNS 请求数，不声称广告数。

边界：无法过滤缓存、同域广告、应用自带 DoH/DoT、直连 IP；系统严格私人 DNS 可能绕过 DNS 过滤或导致解析失败，需要在设备中关闭；UDP DNS 转发为首版范围，不提供完整 TCP DNS 隧道。应用筛选依据包列表，不扫描应用内部代码或识别所有广告 SDK。包列表不上传，日志不记录浏览域名。

实现模块：MainActivity（界面与权限）、Prefs（配置）、RuleSet（规则）、DnsPacket（报文解析与响应）、FilterVpnService（生命周期、隧道和转发）。

验证：构建 debug APK、Android lint、签名与包元数据检查；JVM 报文测试覆盖域名边界、白名单、畸形数据、DNS 响应、IPv4 校验和。无已授权真机或模拟器时明确报告真机功能待测，不把编译成功当作过滤效果验证。

# 0.4.5 误触广告风险修正

用户报告住理生活加载页正常，随后广告闪现，立即跳到推广内容，期望直接进入首页。现有代码确实含有两条风险路径：文字节点不可点时点击相近父节点/模拟坐标手势，以及请求被接受后对同一区域再发一次手势。没有真机日志，不能证明本次跳转具体由哪条路径或应用自身触发。

本版删除所有手势注入和父节点点击代码，并将无障碍配置canPerformGestures明确设为false。唯一动作是向跳过节点自身发出ACTION_CLICK：该节点必须可见、启用、自己可点击、公开点击动作、非输入框/滚动容器；文本和描述没有冲突，且所属包、当前活动窗口ID、实时文字及尺寸都通过校验。没有明确直接动作时只记录原因，不使用坐标替代。文字为跳过但描述为立即进入、下载、广告详情、滑动等不支持的语义时拒绝动作。

每次进入只允许预留一个动作名额，无论系统接受、拒绝或抛错，都不再次发送。接受后仅观察原控件，最多观察到下一轮或窗口结束；不按原区域补点。诊断本机新增是否发出控件点击、是否被系统接受，保留既有隐私边界。减少自动跳过覆盖是此次明确的取舍，不能为覆盖率重新启用模拟触摸。

保留0.4.4的扫描限频、仅开屏跳过方式和VPN更新协调。发布0.4.5/构建11，不修改旧版资产。验证文本/描述冲突、一动作预留、当前会话和过期限制，新增发布守卫禁止手势、父节点和全局动作路径；核对打包后的配置和DEX无手势引用。无连接真机，不保证应用自身无误导控件、摇动触发或其他自动跳转，也不把本次修改宣称为已真机根治。

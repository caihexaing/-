# 0.4.3 开屏跳过兼容与本机诊断

用户提供 WakeUp课程表截图：左下角圆形“跳过”，下方“广告”，右上角“立即进入”是推广入口。截图不能证明无障碍可读性；不声称已取得该应用的控件树，也不按截图坐标点击。

沿用选中应用、总开关、授权、解锁和进入前台15秒限制。扩大读取到最多1200个节点、32层、24个候选，采用广度优先，读取未标为重要的控件，遍历不可见祖先下的可见后代。候选自身仍必须可见、启用、尺寸受限且文字明确。控件暂时缺失时在原时间窗内继续轮询。

默认普通“跳过”仍需要倒计时或广告标识；“跳过广告/关闭广告/Skip Ad”本身提供明确广告语义。最近诊断可为该选中应用单独开启纯“跳过”兼容，用户会看到可能跳过教程/引导的说明，默认关闭，不影响其他应用，也不识别推广入口或普通关闭按钮。

系统接受点击不立即结束：下一次读取若同一位置仍有符合规则的按钮，在至少1秒后用该控件当前中心手势补一次。最多两次总尝试；其他位置的按钮不作为重试目标。若原按钮不再可读，仅记“原按钮未再读到”，不当作已消除广告。

设置增加最近跳过诊断，仅保存最近目标包、时间、节点数和固定原因码；不保存控件文字、截图、广告内容，不上传。保留缺少广告标识、未读到跳过、窗口不可读、扫描触顶、点击被拒绝、请求已接受但仍可见等区分。返回净屏后不会被净屏自身窗口覆盖。可清除记录。

验证：纯Java规则和重试边界检查、已有核心检查、Android编译和Lint，GitHub发布0.4.3/构建9并核对线上APK、签名和更新源。未连接真机，不宣称已修复WakeUp实际广告；若仍失败，以本机诊断指导下一步，不增加盲坐标。

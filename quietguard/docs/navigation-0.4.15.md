# 0.4.15 入口整理

问题：顶部详情、设置及子面板反复提供相同功能，嵌套弹窗和重复说明造成导航混乱。

首页仅保留主状态、暂停/恢复、展开、搜索筛选、批量开关与应用列表。展开区显示范围、跳过/网络连接及统计，没有设置入口或二次折叠。

设置显示5项导航：开屏跳过与权限（权限操作和唯一诊断入口）、应用豁免（全局唯一豁免操作）、防护方式与网络（保守默认、重连、DNS和例外）、版本更新（检查/自动检查/反馈）、帮助与隐私（说明）。主菜单选择后关闭再展示子面板。

应用兼容统一保留列表长按入口，移除诊断中的快捷操作；长按兼容面板不再重复提供豁免。权限完整风险仍在授权前展示；查看设置不能启动防护。所有配置保持原值。

验证：真机检查首页无设置重复按钮、主菜单5项、子页内容与返回、诊断单入口、兼容面板不重复豁免；比对应用配置不变；构建及lint。

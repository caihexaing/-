# 0.4.0 应用内更新

用户明确要求更新不跳转浏览器，并显示进度。保留 GitHub Release 及 update.json 的发布方式；点击“立即更新”后由 DownloadManager 在 APK 内发起 HTTPS 下载。弹窗显示真实字节进度、百分比和速度，提供取消、重试、收起及下载完成后的“安装更新”。未知文件总长度显示不确定进度，不编造百分比。

下载交给系统 DownloadManager，可在后台继续，任务 ID 与更新信息保存在本地；返回界面、旋转或进程重建后恢复进度。用户取消后移除下载任务。完成后复制到应用私有缓存，校验 SHA-256、包名、版本名/版本号和当前应用签名，校验通过才开放安装。临时 ContentProvider 只给系统安装程序读取指定的已校验 APK，不公开普通文件。

首次安装更新需要用户授予“允许安装未知应用”；返回后继续已明确请求的安装。安装仍通过安卓系统确认界面，不提供静默安装，不显示虚构的系统安装百分比。安装被取消后可回净屏重试。下载/校验失败显示原因并可重新下载；网络等待显示真实等待状态。

0.3.0 及更旧版本没有这段下载代码，因此用户需先手动安装 0.4.0 一次，从之后的更新开始使用内置进度下载。升级版本 0.4.0/versionCode 5，保留旧证书覆盖兼容性。

验证：核心完整性测试包含正确文件、损坏、截断、空文件、超限、无效校验值、取消与未知长度进度，保留现有 DNS、版本和开屏测试；编译和 Lint；GitHub CI 自动构建发布，下载线上 APK 验证签名和校验值。当前无连接安卓设备，下载 UI 和系统安装交互仍待真机测试。

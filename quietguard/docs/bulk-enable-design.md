# 0.4.8 一键开启普通应用

用户明确选择：开启所有普通应用的防护，保留各应用兼容设置。

首页数量旁提供一键开启按钮。批量范围为完整扫描结果中的普通应用，不采用visible筛选结果；排除FLAG_SYSTEM和FLAG_UPDATED_SYSTEM_APP，现有扫描已排除净屏自身及禁用应用。以当前selected集合为基础取并集，故已有选中的系统应用保留。只写入apps键一次，不改skip_only_apps、skip_plain_apps或skip_text_tap_apps，不改域名例外或上游DNS。然后刷新列表并调用现有requestStart一次，复用授权和更新VPN暂停规则。没有普通应用时不改选择，提示刷新。

扫描开始禁用按钮，成功后启用，失败保持禁用，避免按部分读取结果执行。重复点击不重复添加。已选全部且防护暂停时仍可调用启动；系统首次授权不是批量功能可以绕过的。后续安装应用不会自动扩大选择，需刷新后再点击。

这是界面和批量保存的小范围变更，沿用现有检查并执行编译与Lint；核对APK版本、签名和公开更新源。不改0.4.7开屏识别和动作，不声称所有应用均能去广告。无连接真机，不能声称已验证新按钮渲染或各应用联网效果。

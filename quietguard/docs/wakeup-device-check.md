# WakeUp课程表设备验证

1. 安装0.4.3（构建9），确认 WakeUp课程表开关已打开、总防护开启且开屏跳过已就绪。若服务未连接，在系统无障碍中重新开启净屏。
2. 退出并重新打开 WakeUp，观察是否自动点击左下角“跳过”。没有消失则回净屏 → 设置 → 查看最近跳过诊断，确认记录的应用确为 WakeUp。
3. 若曾读到跳过，但没有可读取广告标识：在诊断中点“此应用兼容设置”或长按列表中的 WakeUp，阅读教程误跳提示后开启，再退出并重新进入 WakeUp。
4. 若纯跳过兼容开启后仍显示未读到跳过文字，截图可见按钮可能没有向无障碍暴露文字。本版不含截图OCR，不按固定位置点击，需进一步收集设备证据。
5. 若显示两次尝试后按钮仍在，说明点击未确认生效；将诊断页面截图用于后续定位，不把点击次数作为成功证明。
6. 关闭 WakeUp开关、暂停防护、进入未选择应用或锁屏时，均不得点击。纯跳过兼容关闭时，普通无广告标识的教程跳过不得点击；开启后可能跳过该应用教程。

开发机尚无连接真机/模拟器；上述步骤是待设备执行的验收，不是已经通过的结果。

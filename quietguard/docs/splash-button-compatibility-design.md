# 0.4.6 小型语义按钮兼容

用户提供住理生活（com.whxinna.userplatform）的0.4.5诊断：曾读到跳过和广告标识、最多5节点、最高13ms、未达上限、纯跳过兼容已开，未发送点击；最后原因为暂时无法读取当前窗口。该图确认未执行跳过，不能证明具体拒绝条件，也不包含实际控件树。源码可复现两项缺口：只允许文字自身点击，无法识别由外层小按钮响应的结构；后续无窗口状态会覆盖先前按钮拒绝原因。

优先使用明确跳过控件公开的ACTION_CLICK，允许公开动作但clickable标志未同步的虚拟节点。文字没有动作时，最多检查两层外层；遇到含其他语义、可编辑、滚动、不可见、失效、跨包/窗口或体积过大即停止，不向更远祖先回退。按钮必须包住原文字，宽高各不超过其3倍，横向每侧额外不超过32dp，纵向每侧不超过16dp，并通过既有相对窗口尺寸限制。

外层按钮的整个子树必须完整可读，最多12节点、深度3，调用间检查80ms预算。所有节点必须属于当前包和窗口、可见启用、无其他可点击后代；只允许空包装层、明确跳过、纯数字倒计时、短广告标识。未知图标叶子、其他文字、两个跳过叶子、循环或缺失子节点均拒绝。必须确实遍历到原文字。每轮候选检查另有120ms预算。单次系统IPC仍可能超过预算，这不是硬实时保证。

点击前再次核对当前前台和同一个语义按钮，仍使用SplashWindow的一次动作预留；没有坐标或全局动作，系统拒绝或抛错也不补点。此设计有意调整0.4.5一律不读父节点的限制，替换为可测试的完整小按钮核对，绝不恢复旧版仅凭距离/大小点击父容器的路径。

SplashDiagnostic按优先级保留关键结果：窗口暂不可读0、未找到文字1、具体按钮拒绝2、点击结果3。最近状态单独展示。新目标会话重置优先级、动作窗口和目标类型。只保存固定原因和既有元数据，不保存控件文字、资源ID或截图。

通过生产解析器处理模拟控件树，覆盖直接按钮、分离倒计时、两层包装与拒绝场景，检查所有节点引用回收和诊断优先级。沿用单动作、更新与路由检查，源码守卫禁止手势/全局动作并要求语义解析入口。发布核对APK配置、DEX、签名、版本和公开更新源。没有连接真机，不能声称实际住理生活跳过已验证；广告SDK可能只提供图片、虚假语义或其他触发跳转，本版仍可能放弃。

# 无障碍快捷开启（0.4.9）

目的：经手机主人一次明确授权后，在APP内点击即可开启净屏自己的无障碍服务，之后无需持续连接电脑。此方案不需要Root，不解锁或修改系统镜像。普通APK安装不能自行获得安全设置写权限。

## 一次配置

电脑安装Android平台工具，手机打开USB调试并允许该电脑。确认目标设备后执行（多设备时指定 `-s 设备序列号`）：

```text
adb shell pm grant cn.quietguard.app android.permission.WRITE_SECURE_SETTINGS
```

在净屏设置页确认“快捷开启：已授权”，点“开启开屏广告跳过”，首次阅读并同意用途说明，返回首页确认“已就绪”后即可拔线。若被系统拒绝或服务未连接，按界面提示到系统无障碍设置检查。首次VPN授权和安装更新确认仍由系统处理。

## 行为

只在用户点击时读取服务列表，精确比较完整/缩写组件名，追加自身并保留其他无障碍服务，再开启全局无障碍并读回；状态以服务实际连接为准。已连接时重复点击不重写列表。默认不后台反复强开，不绕过首次用途同意。既有应用选择、防护方式、文字定位兼容不变。

权限由手机系统保存，设置与服务在手机端执行，USB连接不是后续按钮工作的条件。卸载、撤权、恢复出厂或厂商策略变化可能需要重新配置；未测试重启持久性。需要撤销快捷设置权限时可执行 `adb shell pm revoke cn.quietguard.app android.permission.WRITE_SECURE_SETTINGS`，也可在系统设置中直接关闭服务。

## 验证

16项纯JVM新增断言检查空值、精确匹配、完整/缩写组件、重复调用、其他服务保留。现有451项逻辑断言、13项源码守卫、20000组随机报文保持通过，编译和Lint通过（0错误、2条既有警告）。

iQOO12（Android16）覆盖安装0.4.9后授予权限，从净屏按钮开启服务，系统确认已绑定，前台仍为净屏；再次点击保持服务列表，原102个已选应用及各项兼容设置保持。未在该测试中物理拔线、重启或重新验证实际广告跳过。本次功能改善开启流程，不扩大广告识别能力。

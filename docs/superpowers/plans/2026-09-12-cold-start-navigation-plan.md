- [x] 现有单元测试和新增状态/分类回归测试通过。

## 后续优化

- 根据真机脱敏页面树增加页面夹具和版本适配规则。
- 用页面变化事件替代更多固定冷却，并补充 T0 到查询、预订、提交和订单号的耗时埋点。
- 在用户允许的前提下增加厂商后台启动/电池策略的设备引导。

## 边界

不调用未公开下单接口，不绕过验证码、登录、身份核验、风控、候补协议或支付；不保存或导出账号、证件、手机号和支付信息；不保证抢票成功或固定时间生成订单。
